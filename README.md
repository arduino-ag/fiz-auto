# fiz-auto

A programm for using a two-motor car with a bluetooth modul and a ultrasonic sensor. The car is controllable with the App [Dabble](https://ai.thestempedia.com/docs/dabble-app/getting-started-with-dabble/).

## button layout

| button   | action                      |
| -------- | --------------------------- |
| up       | driving forwards            |
| down     | driving backwards           |
| left     | left spin and indicators    |
| right    | right spin and indicators   |
| cross    | not assigned                |
| circle   | lightning on/off            |
| triangle | hazard warning lights       |
| square   | driving backwards for 300ms |
| start    | starting the car            |
| select   | not assigned                |
